What should my files look like?

Counts table: one row per sample and one column per bacterium, with read counts or relative abundances. The first column holds sample IDs. Each column's lineage goes either in a last row named taxonomy:

ID,       ASV1,          ASV2,          …
sample1,  120,           0,             …
sample2,  37,            5,             …
taxonomy, k__Bacteria;…, k__Bacteria;…, …

or in the column names themselves (empty ranks such as p__ are fine):

ID,         k__Bacteria;p__Firmicutes;…, k__Bacteria;p__;c__;…, …
ERR1549010, 0.0312,                      0,                     …
ERR1549011, 0,                           0.0047,                …

YaMAS output (16S): upload its two files together, as YaMAS wrote them; we join them into a counts table, keep the read counts and write each lineage in the standard form. otu.csv has one row per OTU and one column per sample; taxonomy.csv has the same OTU IDs and a Taxon column:

OTU,     sample1, sample2, …
a1f3c9…, 120,     0,       …
7be0d2…, 37,      5,       …
OTU,     Taxon,                           Confidence
a1f3c9…, d__Bacteria; p__Firmicutes; …,   0.98
7be0d2…, d__Bacteria; p__Bacteroidota; …, 0.91

Labels (optional): sample IDs in the first column and the outcome in a column named Tag, for example sick/healthy or an age.

ID,      Tag
sample1, 1
sample2, 0

Metabolite table (optional, for linking bacteria to metabolites): sample IDs in the first column, the same as in the counts table, then one column per metabolite with the measured concentrations or intensities (not log-transformed; 0 means not detected). At least {{ min_metabolite_columns }} metabolite columns, and at least {{ min_paired }} samples that are also in the counts table.

ID,      Acetate, Butyrate, …
sample1, 5210.4,  830.2,    …
sample2, 4480.0,  0,        …
